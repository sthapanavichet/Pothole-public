# Milestones Plan

Create these milestones in GitHub and assign issues accordingly.

1. Hardware Integration
- Scope: CAD enclosure design, IoT module fit, mounting validation
- Example linked issues:
  - As a Hardware Engineer, I want a CAD enclosure that fits the sensor and IoT modules so that the deployed unit is compact and protected.

2. Firmware Data Pipeline
- Scope: embedded sensing, event logic, transmission reliability
- Example linked issues:
  - As a Firmware Developer, I want embedded firmware to collect accelerometer and GPS data so that road-surface events can be detected and transmitted.

3. Software Visualization
- Scope: data ingestion display, map view, timeline filtering
- Example linked issues:
  - As a Data Reviewer, I want a dashboard that visualizes pothole events on a map and timeline so that I can prioritize road maintenance.

4. End-to-End Validation
- Scope: integrated system validation and reliability checks
- Example linked issues:
  - As a Project Integrator, I want a validated hardware-firmware-software data pipeline so that sensor events appear reliably in the dashboard.
