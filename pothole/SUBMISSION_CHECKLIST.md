# Project Integration Submission Checklist

1. README includes team table and 2-3 paragraph non-technical description.
2. `docs/WORKING_AGREEMENT.md` includes all required sections.
3. `docs/CHANGELOG.md` includes date, short change description, and PR link.
4. GitHub issues created from `issues/BACKLOG.md`.
5. Fully written issue per student includes template sections.
6. Milestones created and issues assigned.
7. Kanban board created with required columns.
8. Final PDF assembled with required screenshots.
