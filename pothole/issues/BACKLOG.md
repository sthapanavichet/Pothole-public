# Backlog Draft (User Story Titles)

## Fully Written Issues (ready now)
1. As a Hardware Engineer, I want a CAD enclosure that fits the sensor and IoT modules so that the deployed unit is compact and protected.
2. As a Firmware Developer, I want embedded firmware to collect accelerometer and GPS data so that road-surface events can be detected and transmitted.
3. As a Data Reviewer, I want a dashboard that visualizes pothole events on a map and timeline so that I can prioritize road maintenance.
4. As a Project Integrator, I want a validated hardware-firmware-software data pipeline so that sensor events appear reliably in the dashboard.

## Remaining Story Titles (expand later)
1. As a Firmware Developer, I want configurable sampling rates so that battery usage can be optimized.
2. As a Hardware Engineer, I want vibration-resistant mounting features in the CAD design so that modules remain stable in the field.
3. As an Analyst, I want event filtering by severity and date range so that trends are easier to analyze.
4. As a Team Member, I want deployment logs linked to each test run so that field debugging is traceable.
