# Testing and QA GitHub Issue Backlog

## Title: Unit tests for core functions

## User Story

As a Developer, I want automated unit tests for core project functions so that code changes do not break existing functionality.

---

## Description

Create unit tests for the main functions, components, or API logic in the project. Tests should cover expected behavior, edge cases, and common failure scenarios.

---

## Acceptance Criteria

* [ ] Testing framework is installed and configured.
* [ ] Core functions/components have unit tests.
* [ ] Tests can be run locally with one command.
* [ ] Unit tests are included in the project repository.

---

## Testing Criteria

* [ ] At least 5 unit tests are created.
* [ ] All unit tests pass locally.
* [ ] Test results are shown in terminal output or screenshot.

## Title: End-to-end testing for the user workflow


## User Story

As a QA Tester, I want end-to-end testing for the main user workflow so that the application can be verified from start to finish.

---

## Description

Create an end-to-end test for the main user workflow in the application. This should verify that a user can complete an important process without errors.

---

## Acceptance Criteria

* [ ] Main user workflow is identified.
* [ ] E2E testing tool is selected, such as Playwright or Cypress.
* [ ] Test checks that the workflow completes successfully.
* [ ] Test steps are documented for repeatability.

---

## Testing Criteria

* [ ] At least 1 complete E2E test is created.
* [ ] E2E test runs successfully.
* [ ] Evidence such as screenshots, logs, or test output is attached to the issue or PR.
