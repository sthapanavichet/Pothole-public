# Scrum Presentation Prep (Friday)

Present directly from the repository in this order:

1. README walkthrough
- Explain problem, users, and high-level solution (hardware + firmware + software).

2. Working agreement highlights
- Show communication expectations, accountability rules, and merge/testing workflow.

3. Milestones and linked issues
- Open `planning/MILESTONES.md` and show how issues map to each phase.

4. Student issue ownership
- Each student should point to their assigned issues.
- At least one fully written issue per student should include description, acceptance criteria, and testing criteria.

Suggested questions to be ready for:
- Why these milestones were chosen
- How issue scope was defined
- How testing will be verified before merge
- How integration risk is being managed across hardware, firmware, and software
